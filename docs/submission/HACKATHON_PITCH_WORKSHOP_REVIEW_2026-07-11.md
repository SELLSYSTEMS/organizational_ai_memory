# Hackathon Pitch Workshop Review

This review distills the complete operator-supplied AABW workshop recording
from July 11, 2026. The private phone recording was reviewed end to end with a
word-timestamp transcript and full-resolution slide frames. The original file,
speaker audio, attendee faces, GPS, device model, and creation metadata are not
part of the public release.

## Timing Conflict

The workshop recording says `5 minutes + 2 minutes Q&A`. The current public
[AABW page](https://aabw.genaifund.ai/) describes `3 minutes + 1 minute Q&A`
for Round 1 and `7 minutes + 3 minutes Q&A` for Round 2. It also states a
`09:00, July 12` submission deadline. The latest assigned portal slot and onsite
instructions are authoritative. The team must carry adaptable three-, five-,
and seven-minute versions.

## Decisions Applied

1. Lead with P5 organizational capability reuse. Personal Memory Agent
   isolation is the differentiating governance mechanism, not a second product.
2. Produce a 55.5-second live-pitch demo and a separate 177-second,
   under-three-minute submission/backup video.
3. Put task search, decisions, citations, provenance, and user outcome before
   identity provisioning details.
4. Show only representative synthetic scenarios and verified system evidence.
   Automated tests are execution evidence, not user testimonials.
5. Keep the deterministic record authoritative. Label generated and fallback
   Spark outcomes exactly as captured.
6. Use no workshop footage or audio in the final product videos.
7. Strip source metadata, validate captions, and test the final exports from
   beginning to end before upload.
